HERO DESIGN SYSTEM

Référentiel visuel des composants hero utilisés sur Ciné Délices. Deux variantes partagent la même vignette standard pour assurer la continuité visuelle entre le bas du hero et le fond de page. La page Movies est la référence de design — toutes les autres pages y sont alignées.

⚡
Principe clé : la vignette radial-gradient(ellipse 100% 110% at 50% 105%, var(--bleu-nuit) 0%, rgba(20,34,52,.55) 35%, transparent 65%) est identique sur tous les heroes. Elle assure le fondu vers --bleu-nuit (#142234) qui se fond naturellement dans la couleur html #0d1b2a.

Comparaison couleurs vignette — pourquoi bleu-nuit ?

Bleu Nuit (#142234)
var(--bleu-nuit) = #142234
Correspond au gradient mid du hero. Le fondu est imperceptible car la couleur de la vignette ≈ la couleur du hero. L'html bg (#0d1b2a) complète la transition vers le fond page.
Ink (#0a1220)
var(--ink) / --ca-ink = #0a1220
Trop sombre / quasi-noir. Crée une bande visible entre le bleu du hero (#142234) et cette couleur (#0a1220). Le seam est perceptible à l'œil nu — à éviter.

Application par page PAGES & VARIANTES
/movies
Films
Type 1 · Référence
Page mère du design system hero. Toutes les autres pages sont alignées sur celle-ci. Bobines animées + fond dégradé radial rouge/or + vignette bleu-nuit.

Type 1 · Gradient
Même architecture que movies. Hero contient en plus : tabs navigation (Équipe / À propos / Contact) et cards portraits. Utilise ses propres classes .ca-*.

Type 1 · Gradient
Classes .arm-hero. Utilise margin-top: var(--nav-h) (variable correcte — --nav-height était un bug avec fallback 68px).
/recipes/:slug

Type 2 · Image
Photo affiche du film en fond. Overlay directionnel gauche/droite pour lisibilité. Vignette standard ajoutée (couche supplémentaire sur l'existant).
/recipe/:id
Détail Recette
Type 2 · Image
Photo du plat en fond. Mêmes layers que fiche-film. Classe .recipe-hero__vignette ajoutée en + des overlays existants.
/profil
Profil Utilisateur
Type 2 · Image
Bannière personnalisée de l'utilisateur. Vignette alignée avec movies (50% 105% / .55 au lieu des anciennes valeurs).
/
Accueil
Pas de hero
Slider plein-écran à la place du hero. Ne fait pas partie du design system hero.
/admin/*
Administration
Pas de hero
Interface backoffice avec son propre système de design (tableaux, modales). Exclu du référentiel hero.
📐
Full-bleed pattern : toutes les pages hero ont body.xxx-page { padding-top: 0 } + hero en premier enfant du <main> (ou avec margin-top: var(--nav-h)), ce qui permet au hero d'occuper toute la largeur viewport sans être contraint par les paddings de base.css.

# dwwm-cinedelices  

---  

## La présentation du projet  

Site dédié aux recettes vu dans l’univers du cinéma. Les visiteurs pourront visualiser les recettes présentes par film,  les filtrer par catégorie (entrée, plat ou dessert) du film sélectionné. Il aura la possibilité de s’inscrire pour avoir l'accès à des fonctions comme l'ajout de recettes, de laisser des commentaires et noter les recettes.
